# Multimodal Data Extraction Pipeline (Handwritten & Invoice PNG Files)

user-friendly  application demonstrating the power of Gemini-3.5-Flash lite, a multimodal LLM capable of understanding both **text and images**, to extract structured data from handwritten and invoice PNG files.


#  Features

Automated Data Extraction: Handles handwritten and invoice PNGs seamlessly.  
Powered by Gemini-1.5-Flash: Uses Google’s multimodal LLM via API for intelligent data extraction.  
Pre-processing Pipeline: Enhances image quality and improves extraction accuracy.  
High Accuracy: Achieved 95% accuracy on handwritten data over 100+ files.  
Scalable & Consistent: Works across diverse input formats with stable performance.  
Interactive UI: Built with Gradio for quick demos and user interaction.
